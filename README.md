# echolog-template

A simple template for creating a new project with echolog.

## Installation

Here is the information on how to install echolog-template (based on xampp, windows).

1. create a new folder in your htdocs folder called `echolog-template`

2. copy the contents of this repository into the `echolog-template` folder (see commands below)

3. open your browser and go to `http://localhost/echolog-template`

## Commands

add remote origin:

```bash
git remote add origin https://github.com/Project-Echolog/template.git
```
